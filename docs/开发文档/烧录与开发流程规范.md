# 烧录优化与开发流程规范

> 2026-09-19 更新

## 烧录命令（必用）

```powershell
idf.py -p COM9 -b 921600 app-flash
```

- **必须带 `-b 921600`**，不依赖环境变量，确保百分百高速
- 烧录时间 ~20 秒（app.bin ~4.88MB）
- 如果 COM9 被占用报错，先 `Get-Process python | Stop-Process -Force` 再重试

## 增量烧录说明

ESP-IDF 没有内置二进制差分烧录。当前已用最优组合：

- `idf.py app-flash`：只烧 app 分区（0x20000），不重烧 bootloader/partition_table
- 全片烧录用 `idf.py flash`（改了 bootloader 或分区表时才需要）
