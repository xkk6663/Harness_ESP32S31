## 0. 背景与目标

本工程基于 esp-bsp 官方示例 `display_audio_photo`（单文件 `app_disp_fs.c` 1032 行，LVGL 文件浏览 + WAV 播放/录音）进行多轮重构，目标是在此骨架上迭代出"设备 ↔ PC 双通道传声机"：

- **UDP 低延迟通话**：端口 50000/50001，20ms 帧，乱序重排 + 丢包补偿；
- **TCP 整段录音**：端口 50002，WAV 落盘；
- **信令通道**：端口 50003。

音频参数：16 kHz / 16 bit / mono = 32 KB/s，20 ms = 640 B/包。

## 2. 阶段二：三层架构解耦

把原单文件 `app_disp_fs.c`（1032 行）拆成三层：

```
main/
├── app/main.c              # app_main() 只做初始化顺序
├── middleware/             # 硬件业务，不依赖 LVGL
│   ├── audio_service.c/h    # ES8389 + I2S + 常驻 audio_task + 命令队列
│   └── fs_service.c/h      # 文件类型识别 + JPEG 解码缓冲
└── ui/                      # LVGL 界面
    ├── ui_disp.c/h
    ├── ui_state.h
    ├── ui_call.c/h / ui_record.c/h / ui_settings.c/h
    └── ui_windows.c/h / ui_file_browser.c/h（后删）
```

依赖方向：app → middleware + ui；ui → middleware 只走 post_cmd/事件回调。

## 3. 阶段三：FreeRTOS 常驻任务 + 命令队列重构

- `audio_service.c` 起常驻 `audio_task`（栈 8192），通过 `s_cmd_queue` 接收 `audio_cmd_t`；
- UI 事件回调只调 `audio_service_post_cmd()`，不直接碰 codec；
- 完成事件通过 `audio_service_set_evt_cb()` 回调通知 UI。

### 3.1 烧录验证与栈溢出修复
- 首次 `idf.py -p COM9 flash`：Hash verified，硬复位成功；
- 启动日志：`audio_task started` / `audio_service ready` 干净；
- 点播放 recording.wav 触发 **Core1 panic: Instruction access fault**，栈帧大量 `0xa5a5a5a5`；
- **根因**：audio_task 栈 4KB 被打穿——`handle_play_file` 栈帧里带 `char path[256]` 的 `audio_cmd_t cmd`（264 字节）叠加 WAV 头/采样信息结构；
- **修复**：栈 4096→8192；三处 `audio_cmd_t cmd` 局部变量改 `static`（单任务访问安全）；
- 二次烧录验证：无 panic、无自动复位。

- `audio_service.c` 改造：

  - `lv_tabview_add_tab` 后遍历 `tab_btns` 子对象加 `LV_OBJ_FLAG_EVENT_BUBBLE`，让 tab 按钮的触摸事件冒泡到 tab_btns；

### 7.5 ESP32-S31 2D-DMA / PPA 调研结论
纠正此前"ESP32-S31 没有独立 2D DMA"的错误判断：
- ESP32-S31 集成独立 **2D-DMA**（AXI 主机，4 TX + 3 RX 通道，非对齐传输，宏块重排，CSC）；
- **PPA**（Pixel Processing Accelerator）：旋转/缩放/镜像/叠加，ESP-IDF 组件 `esp_ppa`；
- **JPEG 硬解**：`esp_video` 组件支持（本工程 idf_component.yml 已含）；
- 实践路径：
  1. **LVGL draw unit 接 PPA**（最大收益）：把 `bsp_display_start()` 换成乐鑫官方 `esp_lvgl_adapter`，开 `LV_DRAW_SW_DRAW_UNIT_CNT=1` + PPA，blit/旋转/混合卸载到硬件；
  2. **壁纸 JPEG 换硬解**：当前 `esp_new_jpeg` 软解，800×480 解码跑了两次，换 `esp_video` JPEG HW Decoder；
  3. 壁纸平移动画用 PPA blit（工作量大，暂缓）。
