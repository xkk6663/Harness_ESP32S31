## middleware 中间层（main/middleware/）

### audio/ — 音频与音频会话

| 文件 | 职责 | 对外 API |
|---|---|---|
| `audio_service.c/h` | ES8389 codec + 常驻 audio_task + 命令队列；**双职责**：命令式（`post_cmd`）+ 流式（`audio_stream_*`） | `audio_service_init` / `audio_service_post_cmd` / `audio_service_set_evt_cb` / `audio_stream_start` / `audio_stream_stop` / `audio_stream_is_active` / `audio_stream_read_mic` / `audio_stream_write_spk` |
| `record_service.c/h` | TCP STREAM 录音、LOCAL 5 分钟 LittleFS 回退和待传补发 | `init` / `post_cmd` / `is_active` |
| `udp_voice.c/h` | UDP 20ms PCM 帧收发；12B 帧头 + 32 槽重排 + 60ms 静音补偿 | `init` / `post_cmd` / `tx_active` / `rx_active` / `set_evt_cb` |
| `session_manager.c/h` | 音频会话互斥（IDLE/UDP_CALL/TCP_RECORD/BT_PUSH） | `init` / `begin` / `end` / `get_mode` |

### bluetooth/ — 经典蓝牙链路

| 文件 | 职责 | 对外 API |
|---|---|---|
| `bt_audio_service.c/h` | A2DP Source + AVRCP CT；连接状态、绝对/相对音量、推流转发 | `init` / `is_connected` / `set_volume` / `set_abs_volume` |
| `bt_push_service.c/h` | 本地推流方案 B2：GMF pipeline（io_file→aud_dec→aud_asrc→aud_enc→io_bt） | `early_init` / `set_uri` / `request_destroy` |
| `link_manager.c/h` | UDP 50003 心跳、PC peer 学习与 ONLINE/OFFLINE 观察者 | `init` / `is_online` / `get_peer` / `add_evt_cb` |

### network/ — WiFi 与网络服务

| 文件 | 职责 | 对外 API |
|---|---|---|
| `wifi_manager.c/h` | Wi-Fi STA：扫描/连接/IP，双事件槽（sys+evt） | `wifi_manager_init` / `start_scan` / `get_scan_results` / `connect(ssid,pass)` / `get_ip` / `is_connected` / `set_sys_cb` / `set_evt_cb` |
| `net_time_service.c/h` | SNTP 校时（ntp.aliyun.com，TZ=CST-8）+ 和风天气 7 天（esp_http_client + esp_crt_bundle + cJSON），每小时刷新，互斥锁持快照 | `start` / `time_valid` / `get_weather` |

### system/ — 板级外设与存储

| 文件 | 职责 | 对外 API |
|---|---|---|
| `button_service.c/h` | 4 ADC 分压按键 + 音量唯一来源（`s_volume` 0..90）+ 音量出口回调 | `button_service_init` / `set_evt_cb` / `set_vol_out_cb` / `get_vol_queue` / `get/set_volume` |
| `led_service.c/h` | RGB LED（GPIO37 WS2812 RMT）；命令队列+LED 任务串行化 | `led_service_init` / `set_status` / `set_rgb(r,g,b)` / `set_on(bool)` / `set_manual(bool)` |
| `fs_service.c/h` | 文件类型识别 + JPEG 解码缓冲 | `fs_service_init` / `get_file_type` |
| `sdcard_service.c/h` | SD 卡挂载（SDMMC 4-bit）+ 常驻 32KB DMA bounce buffer | `sdcard_service_mount` / `get_mount_point` |

## 工具脚本

| 路径 | 用途 |
|---|---|
| `tools/idf_env.local.ps1` | **本地私密配置：和风 API Key / API Host**（UTF-8 with BOM；**已被 .gitignore 忽略，勿提交**） |
| `tools/idf_common.ps1` | 构建/烧录公共前置：加载 IDF v6.1 环境 + 点源私密配置；定义 `Invoke-Build`（吞掉原生命令 stderr，规避 F21） |
| `tools/build.ps1` | 闭环构建 PS 版（自动注入密钥，默认关 ccache，`-UseCcache` 可开） |
| `tools/flash.ps1` | 一键 app-flash + 自动抓串口日志 + panic 检查 |
| `docs/_serial_capture.py` | pyserial 抓启动日志（替代 monitor）；CLI：`--port/--secs/--out/--reset` |
| `skills/esp-idf-closed-loop.md` | 编译/烧录/抓日志闭环 SOP |
| `pc_host/` | Python 3.10+ PC 主机：心跳、UDP/PTT、可选 sounddevice/ASR、TCP WAV/SQLite 录音库 |

> 注：凡是要被 PowerShell 5.1 执行的 `.ps1`，**含中文就必须存为 UTF-8 with BOM**，
> 否则会按 GBK 解码导致脚本静默失效（见 `11_遇到的问题.md` F16）。
>
> ⚠ **构建入口用 `tools/build.ps1`**（内部走 `Invoke-Build`，已把原生命令
> stderr 归到 Warning 流）。PS 5.1 + 中文终端下，原生命令往 stderr 写字节会被判成
> `NativeCommandError`，从而掐断 `idf.py` 调用链、伪装成"cmake 找不到 Ninja"（见 F21）。
