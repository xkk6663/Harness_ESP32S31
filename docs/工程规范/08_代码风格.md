# 08 代码风格

## 格式

- 缩进 4 空格，不混用 Tab；
- 行宽 ≤ 120 字符；
- `{` 不换行（K&R 风格）：
  ```c
  if (x) {
      foo();
  }
  ```
- 函数之间空两行。

## 命名风格

- 函数 / 变量：`snake_case`；
- 宏 / 枚举值：`UPPER_SNAKE`；
- 类型：`lower_snake_t`；
- 不使用匈牙利记号。

## 头文件

- 必须 `#pragma once`；
- `extern "C"` 包裹；
- 按顺序 include：标准库 → ESP-IDF → BSP → LVGL → 本模块。

## 错误处理

- 初始化失败用 `assert()`（开发期），运行期用 `ESP_LOGE` + 降级；
- 不要吞返回值：
  ```c
  // 不推荐
  read(fd, buf, len);
  // 推荐
  ssize_t n = read(fd, buf, len);
  if (n < 0) { ESP_LOGE(...); }
  ```
- 资源配对：`open` 必 `close`，`malloc` 必 `free`，`jpeg_dec_open` 必 `jpeg_dec_close`。

## 日志级别

- `ESP_LOGI`：流程关键节点（"audio_task started"）；
- `ESP_LOGW`：可恢复异常；
- `ESP_LOGE`：错误（仍要继续运行）；
- 不要在高频循环里打日志（每 20ms 一帧的链路禁止 LOGI）。
