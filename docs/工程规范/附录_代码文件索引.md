# 附录：代码文件索引

## APP 层（main/app/）

| 文件 | 职责 |
|---|---|
| `main.c` | `app_main()`：外设/文件系统/服务初始化 → 页面框架启动 |

## middleware 中间层（main/middleware/）

### audio/（音频播放与录音）

| 文件 | 职责 |
|---|---|
| `audio_service.c/h` | ES8389 codec + audio_task + 命令队列；ext 独占租约协议（media_player / xiaozhi / 本地录音三方互斥） |
| `media_player_service.c/h` | 本地 MP3 播放（xiaozhi MP3 集成，仅 MP3 v1 .mp3） |
| `rec_local_service.c/h` | 本地录音（按一次开录、再按一次落盘 WAV 到 /sdcard/music，供 FILES 页回放） |

### camera/（摄像头 + 人脸识别打卡，S8 主战场）

| 文件 | 职责 |
|---|---|
| `camera_service.c/h` | 相机起停/格式拥有权（CAM 240×240 / VIDEO 720p 转移）、V4L2 流、REQBUFS 失败判据翻译与住户报告、起流前"礼貌腾地" |
| `ov3660_fmt.c/h` | OV3660 带寄存器表的格式描述（`VIDIOC_S_SENSOR_FMT` 需要 `format->regs`） |
| `face_service.cpp/h` | 人脸检测（HumanFaceDetect）C 封装 + 4 态状态机 + `unload_sync()`（§73.9/§73.10：按钮 OFF=彻底卸载） |
| `face_quality.c/h` | 录入帧质量门槛（母方案 §6.3 落地） |
| `face_recog_service.cpp/h` | 识别引擎（MSR+MNP 5 点对齐 + MFN 512 维特征），独立加载任务 |
| `face_db.c/h`（face_db/ 子目录） | 人脸特征库：NVS 存储、≤10 人硬上限、增删查 |
| `punch_service.c/h` | 打卡事务：识别→抓帧→JPEG→`/sdcard/attendance/<seq>_<姓名>/` + index.csv；含 `log_delete/log_sync`（§73.5） |
| `capture_service.c/h` | VIDEO 页拍照（720p JPEG） |
| `viewfinder.c/h` | JPEG 软解取景器三件套（acquire/release 计账；`decode_jpeg_mem` 实测宽高 + 16 像素补齐行步长，§73.3） |
| `jpeg_util.c/h` | JPEG 软件编码辅助 |
| ~~`color_hsv.c/h`~~ | **已删除**（§73.12 HSV 颜色识别整功能下线） |

### media/（SD 卡媒体：拍照/录像/文件管理）

| 文件 | 职责 |
|---|---|
| `sdcard_service.c/h`（periph/ 子目录） | SD 卡挂载（`/sdcard`） |
| `record_video_service.c/h` | VIDEO 页录像（AVI/MJPEG 720p） |
| `avi_mjpeg_muxer.c/h` | AVI 封装（已过原生单测） |
| `avi_mjpeg_demuxer.c/h` | AVI 解封装（回放） |
| `file_mgr_service.c/h` | 照片/视频文件管理 + 缩略图两级解码发布（letterbox 等比缩放，§73.11） |

### ai/（小智 AI 对话）

| 文件 | 职责 |
|---|---|
| `xiaozhi_service.c/h` | 小智云端 AI 对话服务（与 MP3 播放经音频租约互斥） |
| `ai_camera.c/h` / `ai_device.c/h` / `ai_speaker.c/h` / `ai_light.c/h` | 小智 IoT 物体抽象（摄像头/设备/喇叭/灯） |

### net/ + periph/（网络与外设）

| 文件 | 职责 |
|---|---|
| `wifi_manager.c/h`（net/） | Wi-Fi STA：扫描/连接/IP，双事件槽 |
| `net_time_service.c/h`（net/） | SNTP 校时（TZ=CST-8）+ 和风天气，打卡时间可信源（R5） |
| `button_service.c/h`（periph/） | ADC 分压按键 + 音量队列 |
| `led_service.c/h`（periph/） | RGB LED（WS2812 RMT） |
| `fs_service.c/h`（periph/） | LittleFS 文件类型识别 |
| `mem_diag.h` | 内存诊断宏/工具 |
