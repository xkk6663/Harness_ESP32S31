# 06 数据类型规范

## 整数类型

- 用 `<stdint.h>` 固定宽度类型，**不要**用 `int` / `long` / `short` 做跨平台变量：
  - 8-bit：`uint8_t` / `int8_t`
  - 16-bit：`uint16_t` / `int16_t`（PCM 采样点）
  - 32-bit：`uint32_t` / `int32_t`（时间戳、长度）
  - 布尔：`bool`（`<stdbool.h>`）

## 字符串

- 路径缓冲固定 256：`char path[256]`；
- 拷贝用 `strncpy` 并留末尾 `\0`：
  ```c
  strncpy(cmd.path, src, sizeof(cmd.path) - 1);
  ```
- 不要用 `strcpy`（除非目标长度确定够）。

## FreeRTOS 类型

- Tick 数：`TickType_t`，延时用宏：
  ```c
  vTaskDelay(pdMS_TO_TICKS(20));
  xQueueReceive(q, &item, pdMS_TO_TICKS(20));
  ```
- 句柄：`QueueHandle_t` / `SemaphoreHandle_t` / `TaskHandle_t`；
- 不要把 tick 当 ms 写。

## 缓冲区

- DMA 缓冲区用 `heap_caps_malloc(size, MALLOC_CAP_DMA)`；
- JPEG 输出缓冲用 `jpeg_calloc_align(size, 16)`；
- 普通缓冲用 `heap_caps_malloc(size, MALLOC_CAP_DEFAULT)`。

## 颜色（LVGL）

- 用 `lv_color_hex(0xRRGGBB)` 宏，不要 `lv_color_make()` 手填 RGB；
- 配色常量集中在每个 ui_*.c 文件顶部 `#define COL_*`，不要散写。
