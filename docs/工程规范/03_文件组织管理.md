# 03 文件组织管理

## 新增源文件必须同步注册 CMakeLists.txt

`main/CMakeLists.txt` 的 SRCS 列表，新增 `.c` 后必须加一行，否则不参与编译。

SRCS 按**领域分组 + 注释分隔**组织，加文件时放进对应分组，不要随手追加到末尾。

```cmake
idf_component_register(SRCS
    # ---- app 层：入口编排 ----
    "app/main.c"

    # ---- middleware / audio：音频与音频会话 ----
    "middleware/audio/audio_service.c"
    "middleware/audio/record_service.c"
    "middleware/audio/udp_voice.c"
    "middleware/audio/session_manager.c"

    # ---- middleware / bluetooth：经典蓝牙链路 ----
    "middleware/bluetooth/bt_audio_service.c"

    # ---- middleware / network：WiFi 与网络服务 ----
    "middleware/network/wifi_manager.c"

    # ---- middleware / system：板级外设与存储 ----
    "middleware/system/button_service.c"

    # ---- ui / common：公共部件与主题 ----
    "ui/common/ui_common.c"

    # ---- ui / pages：全屏页面 ----
    "ui/pages/page_main.c"

    # ---- ui / tabs：主框架内的标签页 ----
    "ui/tabs/tab_call.c"

    # ---- ui / overlays：浮层（壁纸 / 粒子） ----
    "ui/overlays/overlay_manager.c"

    # ---- ui / assets：字体与图标资源 ----
    "ui/assets/fonts/lv_font_cn_20.c"
  INCLUDE_DIRS "."
                "ui/ui_manager"
  PRIV_REQUIRES ...)
```

## 头文件包含关系

- `main/CMakeLists.txt` 的 `INCLUDE_DIRS "."` 已包含 main 根目录；
- include 路径从 `main/` 根开始写完整路径，例如：
  - `#include "middleware/audio/audio_service.h"`
  - `#include "middleware/bluetooth/bt_audio_service.h"`
  - `#include "middleware/system/button_service.h"`
  - `#include "ui/pages/page_main.h"`
  - `#include "ui/tabs/tab_call.h"`
  - `#include "ui/overlays/overlay_wallpaper.h"`
  - `#include "ui/common/ui_theme.h"`
- 不要写 `#include "../middleware/foo.h"` 相对路径。

### ⚠ 禁止裸文件名 include（踩坑记录 F25）

**不能**写 `#include "ui_theme.h"` 这种不带目录的裸文件名——除非该头文件与源文件
在**同一个目录**。

历史原因：早期所有 UI 文件都平铺在 `ui/` 下，`#include "tab_call.h"` 靠"源文件所在
目录"就能命中，编译器不会报错。但目录分层后，`ui/pages/page_main.c` 里的
`#include "tab_call.h"` 会去 `ui/pages/` 找，**找不到 `ui/tabs/tab_call.h` → 编译失败**。

本次分层一次性修正了 **49 处**这类裸 include。新增代码请直接写完整路径，
不要依赖"同目录"这个隐含前提。

> 判定口诀：**只要 include 的目标不在本文件所在目录，就必须写全路径。**

## 全局对象集中管理

跨 UI 文件共享的 LVGL 对象指针必须在头文件里 `extern`，定义在某个 .c 里，
**禁止**在多个文件各自 `extern`。

## 资源文件

- SPIFFS 素材放 `spiffs_content/`，build 时自动打包成 `storage.bin`；
- 放进去的文件会进固件，不要放无关素材；
- 图片必须按目标 LCD 分辨率（800×480）预处理，不要在设备端缩放。

## 变更目录结构时的检查清单

改动 `main/` 下的目录层级时，依次确认：

- [ ] `main/CMakeLists.txt` 的 SRCS 路径全部更新；
- [ ] 全项目 `#include` 路径同步（`grep -rn '#include "' main/` 逐条核对）；
- [ ] 无裸文件名 include 残留；
- [ ] `INCLUDE_DIRS` 是否需要增删；
- [ ] 规范文档同步（01 目录树 / 03 本文件 / 04 命名 / 10 CheckList / 附录索引）；
- [ ] `idf.py build` 0 error。
