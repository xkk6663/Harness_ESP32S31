01

准备 SD 卡

FAT32 格式；设备不自动格式化，exFAT 不支持。其余目录按需自建，空卡即插即用。

02

安装 ESP-IDF

EIM 一键安装 v6.1.x，自动配好 Python venv、交叉工具链与 OpenOCD。

idf.espressif.com
03

编译

分区偏移变更时必须全量，reconfigure 一步不能省。

idf.py reconfigure && idf.py build
04

烧录

全量烧录 app + storage.bin，分区偏移变更时尤其如此。

idf.py -p COM9 flash
05

连接管理端
