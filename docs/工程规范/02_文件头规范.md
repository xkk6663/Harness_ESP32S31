# 02 文件头规范

每个 `.c` / `.h` 文件必须以 SPDX 许可头开头，后接文件说明块。

## 模板

```c
/*
 * SPDX-FileCopyrightText: 2026 Espressif Systems (Shanghai) CO LTD
 *
 * SPDX-License-Identifier: Apache-2.0
 */

/**
 * @file audio_service.h
 * @brief 一句话说清本文件职责
 *
 * 详细说明：
 *  - 本文件属于 middleware 层，不依赖 LVGL；
 *  - 提供哪些 API；
 *  - 典型用法（可选）。
 */
```

## 要点

- `SPDX-FileCopyrightText` 年份写当年；公司/作者按实际；
- `SPDX-License-Identifier` 统一 `Apache-2.0`（沿用 esp-bsp 许可）；
- `.h` 文件必须有 `#pragma once` + `extern "C"` 包裹；
- 头文件里不定义变量，只声明；
- `.c` 文件不需要重复 `@file` 块，但要在文件顶部用 `static const char *TAG = "XXX"` 定义日志 tag。

## 日志 tag 命名

| 层 | TAG 前缀 | 例子 |
|---|---|---|
| middleware | 模块大写 | `AUDIO_SVC` / `WIFI` / `UDP` / `TCP` |
| ui | `UI_<模块>` | `UI_WIN` / `SPLASH` / `UI` |
| app | 小写短名 | `main` / `example` |
