# 03 文件组织管理

## 新增源文件必须同步注册 CMakeLists.txt

`main/CMakeLists.txt` 的 SRCS 列表，新增 `.c` 后必须加一行，否则不参与编译。

```cmake
idf_component_register(SRCS
                        "app/main.c"
                        "middleware/audio_service.c"
                        "middleware/fs_service.c"
                        "ui/ui_disp.c"
                        "ui/ui_splash.c"
                        "ui/ui_call.c"
                        "ui/ui_windows.c"
                        "ui/ui_record.c"
                        "ui/ui_settings.c"
                      INCLUDE_DIRS "."
                      PRIV_REQUIRES spiffs)
```

## 头文件包含关系

- `main/CMakeLists.txt` 的 `INCLUDE_DIRS "."` 已包含 main 根目录；
- include 路径从 `main/` 根开始写，例如：
  - `#include "middleware/audio_service.h"`
  - `#include "ui/ui_state.h"`
- 不要写 `#include "../middleware/foo.h"` 相对路径。

## 全局对象集中管理

跨 UI 文件共享的 LVGL 对象指针必须在 `ui/ui_state.h` 里 `extern`，定义在某个 .c 里，**禁止**在多个文件各自 `extern`。

## 资源文件

- SPIFFS 素材放 `spiffs_content/`，build 时自动打包成 `storage.bin`；
- 放进去的文件会进固件，不要放无关素材；
- 图片必须按目标 LCD 分辨率（800×480）预处理，不要在设备端缩放。
