# 附录：代码文件索引

> 截至 2026-09-13。新增模块后同步更新本表。

## APP 层（main/app/）

| 文件 | 职责 |
|---|---|
| `main.c` | `app_main()`：mount SPIFFS → I2C → display → fs_service_init → audio_service_init → splash_show |

## middleware 中间层（main/middleware/）

| 文件 | 职责 | 对外 API |
|---|---|---|
| `audio_service.c/h` | ES8389 codec + 常驻 audio_task + 命令队列 | `audio_service_init` / `audio_service_post_cmd` / `audio_service_set_evt_cb` |
| `fs_service.c/h` | 文件类型识别 + JPEG 解码缓冲 | `fs_service_init` / `get_file_type` |
| `led_service.c/h` | RGB LED（GPIO37 WS2812 RMT）；命令队列+LED 任务串行化 | `led_service_init` / `set_status` / `set_rgb(r,g,b)` / `set_on(bool)` / `set_manual(bool)` |
| `button_service.c/h` | 4 ADC 分压按键 + 音量互斥锁 + 音量队列 | `button_service_init` / `button_service_set_evt_cb` / `button_service_get_vol_queue` / `button_service_get/set_volume` |
| `wifi_manager.c/h` | Wi-Fi STA：扫描/连接/IP，双事件槽（sys+evt） | `wifi_manager_init` / `start_scan` / `get_scan_results` / `connect(ssid,pass)` / `get_ip` / `is_connected` / `set_sys_cb` / `set_evt_cb` |
| `udp_voice.c/h` | （待建）UDP 低延迟通话 | — |
| `tcp_record.c/h` | （待建）TCP 整段录音 | — |

## ui 层（main/ui/）

### 框架
| 文件 | 职责 |
|---|---|
| `ui_theme.h` | 统一颜色/字体宏（唯一来源，禁止各页面重复定义 COL_*） |
| `ui_manager/page_manager.c/h` | 栈式页面导航 Page_t{create,destroy,name}，Load/Back（返回异步延迟销毁）/BackToMain；本文件在 `ui/ui_manager/` 子目录，CMake INCLUDE_DIRS 已加该路径 |
| `overlay_manager.c/h` | lv_layer_top 浮层互斥调度（仅壁纸） |
| `ui_common.c/h` | 控件工厂：page_root / title_bar / setting_row / placeholder |

### 页面（PageManager 栈）
| 文件 | 职责 |
|---|---|
| `page_splash.c/h` | Page_Splash 开屏壁纸 + 上滑进主界面（秒切） |
| `page_main.c/h` | Page_Main tabview（CALL/REC/SYS）+ page_main_refresh_group |
| `page_wifi.c/h` | Page_Wifi（占位，标题栏带返回） |
| `page_bluetooth.c/h` | Page_Bluetooth（占位，标题栏带返回） |
| `page_rgb.c/h` | Page_Rgb：灯开关 + R/G/B 调色滑块，调 led_service_set_rgb |
| `page_system.c/h` | Page_System 板卡/IDF/WiFi/端口/GitHub 信息（原 SYS 信息移入） |
| `page_wav_player.c/h` | Page_WavPlayer WAV 播放页 + 音频完成回调注册 |

### 主界面 Tab（Page_Main 子组件，不入栈）
| 文件 | 职责 |
|---|---|
| `tab_call.c/h` | CALL tab（UDP 通话占位），tab_call_build |
| `tab_record.c/h` | REC tab（本地 5 秒录音），按钮 static，on_play/on_record_done |
| `tab_sys_entry.c/h` | SYS tab：音量滑块 + WIFI/BT/RGB/System 四行入口，音量 lv_timer |

### Overlay 浮层（不入栈，挂 lv_layer_top）
| 文件 | 职责 |
|---|---|
| `overlay_wallpaper.c/h` | 壁纸 JPEG 解码 + 顶部下拉/上滑手势，build 供 splash 复用 |

## 第三方库（main/3rd/）

| 文件 | 职责 |
|---|---|
| `3rd/ringbuf/ringbuf.c/h` | 纯 C 环形缓冲区（修改自 RT-Thread ringbuff，单生产/单消费无锁），API：`ringbuffer_init/put/get/peek/data_len` |
