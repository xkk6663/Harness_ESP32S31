# 09 常见模式

## 1. 开屏壁纸 + 手势进入

见 `ui_splash.c`：
- `lv_canvas_create` 全屏铺 JPEG；
- `LV_EVENT_PRESSED` 记录起点 y；
- `LV_EVENT_PRESSING` 算 `dy = cur_y - start_y`；
- `dy < -80` 触发上拉回调，在回调里删 splash 层并创建主 UI。

## 2. 深色 AI 风卡片

每个 ui_*.c 顶部统一定义：

```c
#define COL_BG      lv_color_hex(0x0B1120)
#define COL_CARD    lv_color_hex(0x1E293B)
#define COL_BORDER  lv_color_hex(0x334155)
#define COL_CYAN    lv_color_hex(0x22D3EE)
#define COL_GREEN   lv_color_hex(0x34D399)
#define COL_TEXT    lv_color_hex(0xE2E8F0)
#define COL_SUBTEXT lv_color_hex(0x64748B)
```

卡片统一：圆角 16、背景 COL_CARD、边框 1px COL_BORDER。

## 3. JPEG 解码

```c
jpeg_dec_config_t cfg = DEFAULT_JPEG_DEC_CONFIG();
cfg.output_type = JPEG_PIXEL_FORMAT_RGB565_LE;  // 或 _BE if CONFIG_LV_COLOR_16_SWAP
jpeg_dec_open(&cfg, &dec);
jpeg_dec_parse_header(dec, &io, &out_info);
jpeg_dec_process(dec, &io);
lv_canvas_set_buffer(canvas, file_buffer, w, h, LV_COLOR_FORMAT_RGB565);
jpeg_dec_close(dec);
```

- `file_buffer` 由 `fs_service_init()` 统一分配（800×480×2）；
- DMA 输入缓冲用 `heap_caps_malloc(..., MALLOC_CAP_DMA)`。

## 4. 音频命令下发

UI 事件回调只做：

```c
audio_cmd_t cmd = { .id = AUDIO_CMD_PLAY_FILE };
strncpy(cmd.path, user_data, sizeof(cmd.path) - 1);
audio_service_post_cmd(&cmd);
```

不要碰 codec、不要建任务。

## 5. 串口抓启动日志

非交互终端不能跑 `idf.py monitor`，用 `docs/_serial_capture.py`：
- 拉 RTS 复位；
- 读 N 秒；
- 看 `SPLASH:` / `AUDIO_SVC:` / `Guru Meditation`。
