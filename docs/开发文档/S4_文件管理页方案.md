# S4 文件管理页（FILES tab）可执行方案 v1

> 2026-09-26 · 供审阅。分支 `端侧人脸识别`。UI 框架参照 main 主线本地音频播放页
> （`page_wav_player.c`）的范式：**服务任务 + cmd 投递 + 事件队列 + lv_timer 排空**。

---

## 1. 目标与范围（v1）

在 `page_main` 的 tabview 里新增第 6 个 tab **"FILES"**，对 SD 卡（`/sdcard`，FATFS）做：

| 功能 | 说明 |
|---|---|
| 浏览 | 进入/返回目录、列出文件（名 + 大小 + 类型图标），当前只关注 `/sdcard/photos`、`/sdcard/videos` 及根目录 |
| 删除 | 删除选中文件（两步确认）；**录像/拍照进行中整个页只读** |
| 预览照片 | 点 `.jpg` → 硬件解码 → 全屏显示（复用取景器解码引擎，**不新增 1.8 MB**） |
| 播放视频 | 点 `.avi` → MJPEG AVI 逐帧解码播放（PLAY/STOP/进度条） |

**明确不做（v1）**：重命名/移动/新建目录、`/littlefs` 素材区管理、AVI 音轨
（我们的 muxer 本来就只写视频轨）、缩略图列表（解码太贵）。

## 2. 现状盘点（可复用什么）

| 资产 | 位置 | 复用方式 |
|---|---|---|
| SD 挂载 | `middleware/periph/sdcard_service.c`（SDMMC→FATFS `/sdcard`，含电源使能 + 32 KB DMA bounce buffer） | 直接用；`sdcard_service_is_mounted()` 判挂载 |
| 照片 | `/sdcard/photos/IMG_*.jpg`（720p JPEG） | 预览对象 |
| 录像 | `/sdcard/videos/VID_*.avi`（MJPEG AVI，12 fps，无音轨） | 播放对象 |
| 硬件 JPEG 解码 | `viewfinder.c` 单例引擎（esp_driver_jpeg）+ dec_out 1.8 MB + stage 921.6 KB 常驻 | **共享**给预览/播放（见 §4.2），不再吃 1.8 MB |
| AVI 容器 | `avi_mjpeg_muxer.c` 只有**写**（idx1 索引齐全） | 播放侧新写 demuxer，idx1 直接读，不用扫 movi |
| UI 范式 | `page_wav_player.c`：cmd 投递 + 事件队列 + 30 ms lv_timer 排空（线程纪律 F44） | 新 tab 照抄 |
| tab 框架 | `page_main.c` tabview（现 5 个 tab，bar 48 px）；绝对布局范式 `tab_video.c` | 加第 6 个 tab |
| 仲裁 | `camera_service_owner()`（NONE/PREVIEW/MEDIA） | 互斥矩阵见 §5 |

**现状缺口**：全工程没有任何 `opendir/readdir` 代码、没有 AVI demuxer —— 浏览与播放都是净新增。

## 4. 关键设计

### 4.1 线程模型（照抄 page_wav_player / tab_video 范式）

```
LVGL 线程   tab_files：只画 UI；动作 → file_mgr_service_post_cmd()
            lv_timer(30~50ms) 排空事件队列 → 刷新列表/画布/进度
files 任务  （core 0/1、4 KB 栈、做文件 IO 的任务栈必须内部 RAM —— F35 铁律）
            browse（readdir）/ delete（unlink）/ preview+play（fread→解码→发布）
```

### 4.2 解码资源：共享 viewfinder 引擎（本方案最关键的决定）

预览/播放都需要"JPEG → RGB565 全尺寸解码"。两条路：

| 方案 | 内存 | 结论 |
|---|---|---|
| A. 预览自建引擎 + 自配 1.8 MB 出图缓冲 | **+1.8 MB 常驻**（总 PSRAM 大户 3.0→4.8 MB） | 否决：PSRAM 扛不起第二份 |
| B. viewfinder 暴露同步解码入口，共享单例引擎 + s_stage + s_dec_out | **+0** | ✅ 采用 |

```c
/* viewfinder.h 新增（~40 行实现）：
 * 同步解码一段 JPEG → s_dec_out（1280x720 RGB565），返回指针。
 * ★ 守卫：仅当取景器任务停（!s_enabled）且 camera owner 非 MEDIA 时可用；
 *   返回的指针只在下次调用前有效（单缓冲）。 */
const uint16_t *viewfinder_decode_jpeg_mem(const uint8_t *jpg, size_t len, esp_err_t *err);
```

预览/播放的显示：`dec_out`(1280x720) → step2 抽点 → **640x360 显示缓冲**（新常驻
+460 KB，开机随 viewfinder_init 一起拿）→ canvas `transform_zoom 320`（1.25x）→
800x450 铺满屏。抽点循环只读 360/720 行 ≈ 920 KB/帧。

内存账（PSRAM 8 MB）：viewfinder ~3.0 MB + 显示缓冲 0.46 MB ≈ **3.5 MB**（新增 0.46）。

### 4.3 AVI 播放（M3）

- demuxer：读 RIFF/avih/strl 头 → `idx1` 直接拿每帧 offset/size/关键帧标志
  （我们的 muxer 写了 idx1）；容错：无 idx1 则扫一遍 movi 建索引。
- 播放节拍：按 muxer 写入时的 nominal fps（12）定时；每帧 fread → `viewfinder_decode_jpeg_mem`
  → step2 抽点 → 双缓冲发布 → LVGL canvas。SD 读带宽 Q8 帧约 0.7 MB/s，FATFS 无压力。
- 控件：PLAY/PAUSE/STOP + 进度条（帧号/总帧）。**无音轨**（muxer 只写视频），页面标注 "no audio"。

### 4.4 UI 布局（776×408 内容区，绝对定位，参照 tab_video.c）

```
(0,0)    标题 "FILES"          (顶右) 状态行：路径 + 挂载/忙碌状态
(0,42)   文件列表 470x300       (486,42) 信息卡 290x300：
         lv_list，条目=类型图标     当前路径/选中项大小/剩余空间
         +文件名+大小(KB)；             按钮 UP / OPEN / DELETE / REFRESH
         点选=高亮，再点=打开           （DELETE 两步确认：变红 CONFIRM?）
预览/播放态：隐藏列表与操作列，canvas 640x360 居中 (68,36) + zoom 320 → 800x450；
视频底部加进度条 + STOP；tap 画布退出（同 VIDEO 页放大交互）。
```

列表条目上限：一屏 ~7 条 + 滚动；目录规模（photos/videos 各几十个）一次性 readdir 无压力。

## 5. 互斥矩阵（本项目最容易翻车的地方）

| 场景 | 规则 |
|---|---|
| FILES tab 激活 | `tab_video_set_active(false)`（关取景流+取景器）——复用 §29 的钩子位置（`page_main_refresh_group()` 之前） |
| 进入预览/播放 | 前置检查：`sdcard_service_is_mounted()` && `camera_service_owner()==NONE`（或 PREVIEW 且先停）&& capture/record 服务 IDLE && `!viewfinder_is_enabled()`；任一不满足 → 状态行报原因 |
| 录像/拍照进行中 | FILES 页整体**只读**（DELETE/OPEN 全禁用），防止删正在写的文件 |
| 退出预览/播放 | 先停 files 任务动作，再恢复 UI；FILES tab 离开时强制 STOP |

## 6. 里程碑（每步独立可验收）

| 里程碑 | 内容 | 验收 |
|---|---|---|
| **M1** 骨架+浏览+删除 | tab 注册、file_mgr_service（browse/delete）、列表 UI、两步删除 | 进 photos/、videos/ 列出文件；删除后 PC 复核 SD；未插卡有提示 |
| **M2** 照片预览 | `viewfinder_decode_jpeg_mem` + 640x360 显示 + zoom + tap 退出 | Q8/Q1 照片都正常显示、颜色正确（F49 基准）、退出后 VIDEO 页取景器仍正常 |
| **M3** AVI 播放 | demuxer + 播放任务 + 进度/STOP | 录的 AVI 能播、节奏正确、播完/STOP 后文件可再播、录像功能不受影响 |
| **M4** 收尾 | 文档 §33+、记忆、验收清单 | — |

bin 余量：现 0x507ad0 / 6 MB 槽（余 ~996 KB），预计 +40~60 KB，无风险。
