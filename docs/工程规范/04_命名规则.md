# 04 命名规则

## 文件

- 全小写 + 下划线：`audio_service.c` / `ui_call.c` / `fs_service.h`；
- 中间层文件名 = 模块名，不带 `app_` 前缀；
- UI 层文件以 `ui_` 开头。

## 函数

| 类型 | 规则 | 例子 |
|---|---|---|
| 对外公共函数 | `<模块>_<动作>`，小写下划线 | `audio_service_init()` / `fs_service_init()` / `ui_splash_show()` |
| UI 构造函数 | `app_disp_lvgl_show_<tab>` | `app_disp_lvgl_show_call()` |
| 事件回调 | `<对象>_<事件>_cb` | `play_event_cb()` / `volume_event_cb()` |
| 文件内 static 函数 | 小写下划线 | `handle_play_file()` / `splash_pressing_cb()` |

## 变量

- 全局变量：小写下划线，能少就少；
- 文件内 static：小写下划线；
- 跨文件全局：必须在头文件 `extern`；
- 不要用 `g_` 前缀（本工程不强制）。

## 宏 / 枚举

- 宏全大写：`BUFFER_SIZE` / `RECORDING_LENGTH` / `SWIPE_UP_DY`；
- 枚举值带模块前缀：`AUDIO_CMD_PLAY_FILE` / `AUDIO_EVT_PLAY_DONE` / `WIFI_EVT_CONNECTED`；
- 枚举类型名小写下划线 + `_t`：`audio_cmd_id_t` / `audio_evt_id_t`。

## 类型

- 结构体名 = 模块前缀 + 名词：`audio_cmd_t` / `jpeg_dec_io_t`；
- 回调类型：`xxx_cb_t`，如 `audio_evt_cb_t` / `ui_splash_enter_cb_t`。
