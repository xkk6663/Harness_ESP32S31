## 6. 安全与边界

- [ ] 请求 `path=/etc/passwd`、`path=/sdcard/../..` 之类 → 返回
      `{"error":"bad_path"}`，串口出现 `path rejected (...)`
- [ ] 非 AVI 请求 frame 端点 → `{"error":"bad_path"}` +
      串口 `not an avi: ...`
- [ ] 打开不存在的文件 → `{"error":"open"}`，页面缩略图占位不崩
- [ ] 管理端全程**只读**：SD 卡上不产生新文件、不删任何东西（对照
      FILES 页文件数）

## 已知边界（非 BUG，备忘）

1. 视频预览无声 —— 设备 AVI(MJPG) 本身就没有音轨；
2. 打卡事件显示延迟 ~1s（轮询周期）；
3. STA 连路由的瞬间 AP 信道跟随，手机重连一次；
4. 视频逐帧跳转大跨度时有短暂等待（顺序 demux 设计）；
5. mp4/手机原拍视频不在预览范围（无 H.264 解码，当初已砍）。
