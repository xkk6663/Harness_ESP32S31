# 附录：代码文件索引

> 截至 2026-09-13。新增模块后同步更新本表。

## APP 层（main/app/）

| 文件 | 职责 |
|---|---|
| `main.c` | `app_main()`：mount SPIFFS → I2C → display → fs_service_init → audio_service_init → splash_show |

## middleware 中间层（main/middleware/）

| 文件 | 职责 | 对外 API |
|---|---|---|
| `audio_service.c/h` | ES8389 codec + 常驻 audio_task + 命令队列 | `audio_service_init` / `audio_service_post_cmd` / `audio_service_set_evt_cb` |
| `fs_service.c/h` | 文件类型识别 + JPEG 解码缓冲 | `fs_service_init` / `get_file_type` |
| `wifi_manager.c/h` | （待建）Wi-Fi STA 连接 | — |
| `udp_voice.c/h` | （待建）UDP 低延迟通话 | — |
| `tcp_record.c/h` | （待建）TCP 整段录音 | — |

## ui 层（main/ui/）

| 文件 | 职责 |
|---|---|
| `ui_disp.c/h` | tabview 主框架（CALL/REC/SYS）+ `app_disp_lvgl_show_main` + `set_tab_group` + 下拉壁纸手势（挂 tab_btns） |
| `ui_state.h` | 跨文件 LVGL 对象 extern |
| `ui_splash.c/h` | 开屏壁纸 + 上拉手势 + `ui_wallpaper_attach` 公共函数 |
| `ui_call.c/h` | CALL tab（UDP 通话占位） |
| `ui_record.c/h` | REC tab（本地 5 秒录音调试） |
| `ui_settings.c/h` | SYS tab（系统信息 + 音量 + GitHub 名） |
| `ui_windows.c/h` | WAV 播放弹窗 + 音频事件回调注册 |

## 第三方库（main/3rd/）

| 文件 | 职责 |
|---|---|
| `3rd/ringbuf/ringbuf.c/h` | 纯 C 环形缓冲区（修改自 RT-Thread ringbuff，单生产/单消费无锁），API：`ringbuffer_init/put/get/peek/data_len` |

## elab shim（main/elab/common/）

| 文件 | 职责 |
|---|---|
| `elab_def.h` | 第三方 ringbuf 依赖的 elab 基础类型 shim（stdint/stddef/string + `ELAB_SIZE_ALIGN_DOWN` + 空 `ELAB_TAG()`） |
| `elab_assert.h` | `ELAB_ASSERT(x) = assert(x)` |
